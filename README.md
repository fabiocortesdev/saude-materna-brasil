# Painel de Saúde Materno-Infantil — SINASC Brasil

Projeto de portfólio em andamento. Análise comparativa entre as 5 regiões
do Brasil (Norte, Nordeste, Centro-Oeste, Sudeste, Sul) usando dados
públicos do SINASC (nascidos vivos), com foco em indicadores clínicos e
socioeconômicos.

**Status:** 🚧 em construção

## Stack

- Python (extração dos dados via [PySUS](https://github.com/AlertaDengue/PySUS))
- Google BigQuery (armazenamento e SQL)
- Looker Studio (visualização — em breve)
